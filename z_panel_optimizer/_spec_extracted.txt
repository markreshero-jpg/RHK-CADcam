3.2  Operation Types
pocket
Area clearance. Removes all material within the route boundary down to depth. If depth exceeds tool max_depth_per_pass, auto-steps down in increments. Fill strategy: raster or spiral.
outline
Single perimeter pass following the exact route boundary at the specified depth. Used for finishing passes or shallow decorative grooves.
square_off
Corner cleanup using a small diameter tool to reach internal corners that the larger finishing bit left radiused. System calculates which corners need treatment.
profile
Shaped edge pass using a profiled bit (VJ, roundover, cove, chamfer, rebate). Tool follows the perimeter. Tool shape_profile determines the resulting edge geometry.
drill
Single point or pattern drilling. Position defined by coordinates relative to part. Supports repeat patterns (rows, grids).
groove
Straight line route from point A to point B. Defined by start/end coordinates relative to the part, or by edge references. Supports multi-segment paths.
raster
Parallel line passes across the part or defined area. Direction set by raster_angle_deg. Used for surface texturing, fluting, VJ board effects.

5.2  Core Principles
Temporary workspace — no writes to job tables. Parts are read as a snapshot at load time.
Non-destructive — quantity changes and exclusions have no BOM effect
Batch support — multiple projects share sheets for optimal material yield
Snapshot fidelity — G-code generation saves a complete reloadable snapshot

5.3  Batch Project Support
Parts from batched projects are pooled per material group and nested on shared sheets. No job separation on sheets — a sheet may contain panels from multiple projects. Each part retains its job label so cut sheets identify which job each part belongs to.

5.6  Nesting Algorithm
No-Fit Polygon (NFP) nesting with simulated annealing optimisation. Parts grouped by material+thickness before nesting. Within each group sorted by descending area, largest placed first.
NFP handles rectangles and arbitrary polygons (L-shapes, future curves)
Quality slider: Fast (nearest-fit only) | Balanced (light annealing, ~5-15s) | Best (full annealing, ~30-120s)
Rotation: 0°/90°/180°/270° tested for non-grain materials. Grain-locked materials only test grain-preserving rotations.
New sheets opened automatically when current sheet is full
Parts with higher nest_priority (from source part table) placed before lower-priority parts within their material group

5.8  G-code Generation

✖  Drilling and boring always execute before routing. Non-negotiable.
✖  Inside-out sequencing always enforced — internal features before outer profiles. Non-negotiable.

5.8.1  Cut Sequence per Sheet
1
Program header — machine init, work offset, units, safe Z
2
Sheet load pause — M00 if sheet_load_pause = true
3
Dust extraction on
4
ALL drilling/boring across ALL parts — sequenced by drill_sequence_strategy (stripe default)
5
Tool change to routing bit
6
ALL routing — inside-out order, travel-optimised between parts
7
Dust extraction off
8
Spindle off
9
Push-off if enabled
10
Program footer — home, M30

5.8.2  Drill Sequencing Strategies
stripe (default)
Horizontal bands across sheet, left-to-right odd bands, right-to-left even (boustrophedon). Predictable.
nearest_neighbour
Always move to closest unvisited hole. 80-90% optimal, fast.
tsp
Full TSP optimisation. Best result, higher compute. Recommended for 200+ holes.

5.8.3  File Naming
One G-code file per sheet:
Single project: {JobNumber}_{MaterialCode}_{SheetNumber}.nc
Batch run: BATCH_{Date}_{MaterialCode}_{SheetNumber}.nc
File extension configurable per machine profile. Default .nc

7. Phase 2 — Toolpath Simulator
Phase 2 — built after the Panel Optimiser is complete and verified. Specified here so Phase 1 architecture accommodates it.

7.1  What It Shows
Sheet flat in viewport at scale
Spindle head as a scaled circle (tool diameter) with the tool cross-section SVG profile from the tool library
Rapid moves — blue dashed line, no material removal
Drill hits — pulsing circles at each position as they execute
Routing moves — solid cutting line, material rendered removed behind tool
Lead-in and lead-out arcs in a distinct colour
Corner loops and dog-bones at correct scale
Tabs shown as small uncut sections

7.2  Playback Controls
Play / Pause, Speed (1×, 5×, 20×, 100×), Scrub timeline
Step forward / back one G-code line
Jump to start / end
Sheet selector for multi-sheet runs

7.3  Technical Approach
Parses stored G-code text from nest_sheets.gcode into a sequence of 2D moves with metadata. Animates using SVG or canvas rendering at the requested playback speed. No re-calculation — purely replays the stored record.
