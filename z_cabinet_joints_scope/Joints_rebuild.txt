● So the joint length (D) for back seams is:

  For Part A ops → backDX = back panel rendered height:
  backBottom3D = TK + SCRBT

  ---
  New concept: SeamFrame

  This is the key piece that eliminates all the axis-remapping bugs. For every seam at runtime,      
  compute an edge-local coordinate frame from the actual part boxes:

  interface SeamFrame {
    // Which axis holes distribute along (the long axis of the edge)
    alongAxis:   'x' | 'y' | 'z'
    // Cabinet coordinate of the "origin" end (where offset_z_mm = 0 is referenced from)
    alongOrigin: number
    // Sign: +1 means offset adds to origin, -1 means it subtracts
    alongSign:   1 | -1
    // Where the joint interface sits on the drill axis
    interfaceCoord: number
    // Drill direction going INTO part A from the joining face
    drillAxisA: 'x+' | 'x-' | 'y+' | 'y-'
    // Drill direction going INTO part B from its face
    drillAxisB: 'x+' | 'x-' | 'y+' | 'y-'
  }

  Computed automatically from the two part boxes — no hardcoding:

  function seamFrame(seamKey: string, boxA: Box, boxB: Box): SeamFrame {
    const partBKey = seamKey.slice(seamKey.indexOf(':') + 1)
    const isLeft   = partBKey === 'left_side'
    const isRight  = partBKey === 'right_side'

    if (isLeft || isRight) {
      // Interface is a YZ plane at a fixed X
      const interfaceX = isLeft ? boxA.x : boxA.x + boxA.w

      // The "along" axis is whichever dimension of Part A is longer — depth or height.
      // Horizontal panels (bottom, top, rail): d >> h  →  along Z, origin = front face
      // Vertical panels (back):               h >> d  →  along Y, origin = top face
      const alongAxis   = boxA.d >= boxA.h ? 'z' : 'y'
      const alongOrigin = alongAxis === 'z'
        ? boxA.z + boxA.d   // front face of Part A
        : boxA.y + boxA.h   // top face of Part A
      const alongSign = -1  // offset subtracts from origin (front-to-back, top-to-bottom)

      return {
        alongAxis, alongOrigin, alongSign,
        interfaceCoord: interfaceX,
        drillAxisA: isLeft ? 'x+' : 'x-',
        drillAxisB: isLeft ? 'x-' : 'x+',
      }
    }
    // back:bottom and other seams follow similar logic for Y-interface planes...
  }

  That one rule (d >= h → horizontal, h > d → vertical) replaces all the isBackSeam special cases.   
  Back panel: h = 700, d = 6 → vertical → along Y. Bottom panel: h = 18, d = 520 → horizontal → along   Z.

  ---
  Unified operation evaluation

  With a SeamFrame, the drill position calculation becomes the same for every seam — no branching:   

  function applyOp(op, ev, frame, boxA, boxB): { x, y, z, axis } {
    // V (offset_z_mm) = position along the edge from the origin end
    const alongPos = frame.alongOrigin + frame.alongSign * (ev.offset_z_mm + i * spacing)

    // U (offset_y_mm) = position into Part A from its joining face (within its thickness)
    const insetPos = frame.interfaceCoord + (intoPartA direction) * ev.offset_y_mm

    // Assemble the 3D point based on which axis is which
    const pos = { x: 0, y: 0, z: 0 }
    pos[frame.alongAxis] = alongPos
    pos[drillAxis === 'x' ? 'y' : 'x'] = insetPos  // simplified
    pos.x = frame.interfaceCoord  // for left/right seams

    return { ...pos, axis: frame.drillAxisA }
  }

  One function, works for bottom:left_side and back:left_side and front_rail:left_side identically.
