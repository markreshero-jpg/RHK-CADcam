## What it is

```
 ceiling ─────────────────────────────────────────
          │◄──── return depth ────►│
          ┌────────────────────────┐╲  ← mitre (default) or butt
   wall   │ return (L/R, optional) ││ fascia (front panel, exposed colour)
          │                        ││
          ╞══ cleat (L, 100×100) ══╡│  ← against fascia back, bottom edge
 wall-cab top ─────────────────────┴┘
          [ overhead carcase ][door]
```

Side section. In elevation the fascia spans the bulkhead width; returns turn
back toward the wall at either end; a bottom return (under-panel) closes the
underside when the bulkhead isn't sitting on cabinets.

## Locked decisions (Mark, 2026-10-18)

1. **It's a cabinet, placed from F3.** A `BH` library row under Wall → Bulkheads,
   `assembly_class: 'wall'`, no carcase / internals / kick / face zones. All
   sizes (W, H, D) are editable like any cabinet. No new F key (F5 stays free —
   it's browser refresh).
2. **Sits up to the ceiling.** Top = wall height (ceiling); default height =
   ceiling − wall-cab top (i.e. the soffit drop), so it fills above the
   overheads. Height auto-follows soffit / ceiling edits until the user types a
   height (then it's theirs). Bulkhead hangs from the ceiling: a taller height
   drops the bottom, the top stays put.
3. **Front line: flush with doors OR flush with carcase** — a per-bulkhead
   option. D (cabinet depth) stays the carcase depth (class cascade, editable);
   "flush with doors" brings the fascia forward to the overhead door front in
   the resolver (door thickness + face gap, same rule as face fillers).
4. **Material = exposed panel colour** (room/job exposed material, `t.exposed`)
   for fascia and returns. Cleat = carcase board.
5. **Returns: left, right, bottom — each independently on/off**, via
   checkboxes in the sidebar and the canvas right-click menu. Each return has
   its own **depth** field (default **600**, how far it runs back from the
   front, capped at the wall) and **joint** to the fascia: **mitre (default)**
   or butt. Butt = the fascia runs through and the return stops behind it.
6. **Fixing cleat** = an L made of two 100 mm legs (carcase board), full
   width between the returns, against the fascia's back face at its bottom
   edge — upright leg up the fascia back, flat leg running back over the
   overhead tops. **On by default** (toggle). With a bottom return on, the cleat
   **lifts by the bottom return's thickness**. A bulkhead too low for the cleat
   (H < lift + 100) gets none.
7. **Bottom return sits between the side returns**; the side returns run full
   height.
8. **Parts are generated by a resolver module** (`resolveBulkhead`), not
   hand-made custom parts: the return toggles and mitres need real geometry
   (`bevel_lo` / `bevel_hi`, the same mitre mechanism shaped cabinets use), and
   they flow to the cut list, optimiser and 3D like case parts. Hand-fixed: no
   seams / drilling.

## Data

- `cabinet_definitions.bulkhead jsonb` — default settings for a bulkhead row
  (non-null = this definition is a bulkhead). Copied onto the instance at
  placement.
- `cabinet_instances.bulkhead jsonb` — the live settings:
  ```ts
  {
    front: 'doors' | 'carcase',
    auto_h: boolean,                // height follows ceiling − wall-cab top
    h_adjust?: number,              // B11: top above (+) / below (−) the ceiling
    grain?: 'vertical',             // B13: unset = horizontal
    cleat: boolean,
    left:   { on: boolean, depth: number, joint: 'mitre' | 'butt' },
    right:  { on: boolean, depth: number, joint: 'mitre' | 'butt' },
    bottom: { on: boolean, depth: number, joint: 'mitre' | 'butt' },
  }
  ```
- Case part keys `bh:fascia`, `bh:ret_l`, `bh:ret_r`, `bh:ret_b`,
  `bh:cleat_v`, `bh:cleat_h` (case_parts part_key constraint extended).

      `bulkhead.h_adjust` (mm) moves the **top**: + = up past the ceiling (into the

      soffit / ceiling edits. Typing an adjust turns "Height to ceiling" back

      adjust). No schema change (jsonb). Not for shadowlines. Sidebar
      "Height adjust" under Height to ceiling. Tutorial `bulkhead_height_adjust`.

- [~] **B13 — vertical grain** (built 2026-11-11, in-app check pending) (Mark,
      RHK6595: "bulkheads WC-09, WC-08 and WC-11 need to be vertical grain").
      Bulkhead section › Grain: Horizontal (default, unset) / Vertical. Vertical sets
      `grain_direction: 'vertical'` on the fascia and the side / bottom returns
      (cleats and the split rail keep none) and the optimiser nests `bh:` parts

      it splits into equal pieces `bh:fascia_a`, `_b` … left → right (letters, as
      the part_key check allows `bh:[a-z_]+`), end bevels / tape on the outer
      pieces, joins taped (IBP rule). RHK6595 WC-09 2042.5 → 1021.3 + 1021.2.
